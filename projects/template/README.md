# RomLingo project template

Copy this directory when starting a new game-specific project.

Document at minimum:

- exact source revision/hash
- target localization
- translation patch dependency, if any
- text encoding
- pointer/script format
- control codes
- font/glyph notes
- textbox limits
- expansion/repointing strategy
- first vertical-slice scope
- known emulator/hardware test targets

## Agent instructions

Keep verified game-specific rules in `AGENTS.md`. The included `CLAUDE.md` is only a thin Claude Code adapter; do not maintain a second copy of the project's rules there.
