# Language profiles

RomLingo is language-agnostic. A language profile is an optional project aid, not a declaration of supported languages.

- `template.json` is the generic starting point for any target language.
- `es.json` is the Spanish documentation example used throughout the repository.

Create or extend a profile only after considering the actual target language, learner level, localization, writing system, and game-engine constraints. Do not infer teaching rules from a language family alone.
