# Lesson format guidelines

RomLingo lessons are contextual annotations, not textbook chapters.

## Typical lesson

```text
Original localized dialogue

Meaning: concise learner-language translation

word/expression = meaning

Pattern: short grammar explanation
```

Only include sections that add value.

## Density by level

- **A0/A1:** more direct translation, concrete word mappings, minimal terminology.
- **A2/B1:** reusable structures, morphology, common expressions, moderate translation.
- **B2+:** less basic translation; more idiom, register, nuance, and regional usage.

## Repetition

The first meaningful encounter may receive a full explanation. Later encounters should usually receive a shorter reminder, a recall prompt, or nothing if the concept is already familiar.

## Localization integrity

Teach the line actually present in the target localization. Use another language's script only for context, never as proof of what the target localization says.
